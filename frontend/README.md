# Frontend — Diario de Progreso Gamer

Ejecuta `npm install` y `npm run dev`. Configura `VITE_API_URL=http://localhost:3000/api` en `.env` (usa `.env.example` como plantilla). Para verificar el build, ejecuta `npm run build`.

Pantallas: biblioteca, detalle con logros y resumen, crear/editar videojuego, historial de partidas y registrar sesión. Las peticiones HTTP están aisladas en `src/api/`.
